这是一个 Liveware 使用引导页。Liveware 是由你的 agent 托管、能和聊天联动的小应用 —— 下面三个例子带你体验它和对话的双向联动。

① 让 agent 改这个页面

回到对话页,对 agent 说:

修改 Liveware-sample 标题为'新名字'

上方标题会在一秒内实时变化,正文和主题色同理。

② 给 agent 留句话

留言(或点赞)后,回到对话页问 agent:「我在 liveware 页面上做了什么/有人留言吗」—— agent 就能读到并复述你的留言。

③ 从页面一键跳回聊天

确认并返回聊天

当前版本暂不支持一键返回 —— 点左上角 ‹ 即可回到聊天。

输入的内容会作为一条页面事件记录下来,回到聊天后同样可以问 agent。
